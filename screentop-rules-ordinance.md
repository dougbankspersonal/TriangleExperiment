# Gerrymander

# Terminology

## Players

Each player represents a faction of votes united by their hatred of something:

- Red: clonws
- Yellow: Cats
- Green: Vegetables
- Blue: Education

## Tiles

- Each player has their own deck of tiles.
- A tile is a trianglular playing piece with 4 sectors.
- Each sector is one of four neighborhood types: swamp, city, suburb, or farm.
- City, suburb and farm sectors have a symbol indicating which faction inhabits the sector: think of it as a voter.
- Swamp sectors do not have symbols.
- A set of adjacent sectors of the same neighborhood type forms a region of that type.
  - Adjacent means they share an edge: corners do not count.

## Ordinances

Ordinances are rules that apply to the people living in the county:
And ordinance has:

- One, two, or three neighborhood types it applies to.
- Symbols indicating how much different factors like the ordinance.
- Flavor text.

# Game End and Final Scoring

The game ends with the 7th Ordinance is passed, or a player is unable to play a tile.

To score:
For each player, for each neighborhood type:

- Count the number of enemy faction symbols in that neighborhood type.
- Multiply by the sum of all of your faction symbols on Ordinances that apply to that type.

# Setup

Place all Bonus cards face up.
Place all Ordinance cards face up.
Place neighborhood tokens and "passed" tokens by the ordinances.

Each player:

- Shuffles their deck of tiles and draws one.
- Gets a stack of faction tokens and a Ordinance Board.

# Player Turn

- Play a tile
- Maybe allocate tokens.
- Maybe run Referendums.
- Draw a new Tile.

## Rules for Placement

- New tile must be completely over or under played tiles.
- At least one sector of the new tile must be over or under a sector already played.
- At least one sector of the new tile must be neither over nor under a sector already played.
- If the new tile is over played tiles:
  - A swamp sector can cover any sector.
  - Any sector can cover a swamp sector.
  - Otherwise, the covered sector must match the color and/or faction symbol of the covering sector.

## Token Collection and Allocation.

Whenever a new tile causes faction symbols to be covered (whether on new or existing tile), that player must immediatgely allocate one faction token to a space on their Ordinance Board.
If more than one player gets tokens at the same time, start with the active player and proceed clockwise.

## Triggering a referendum

If a space on the Ordinance Board has 3 tokens, a referendum is triggered. That space is now filled (no more tokens call be added there).

The triggering player immediately collects a Bonus card of their choice: this is a one-shot card to be used at any time they see fit.

The player must then run a referendum.

## Running a Referendum.

### Select an Ordinance

The player selects an available Ordinance. If it applies to 1 or 2 neighborhood types the player chooses 1 or 2 (different) neighborhood tokens to assign to the referendum. If all tokens of a type are used, that neighborhood type cannot be selected.

### Count votes

For each neighborhood type on the referendum:
For each region of that that type
Determine dominant players: a player is dominant if no faction has more symbols in the region (there may be tiles)
Dominant players get one vote for each sector in the the region. If there is tie, split the votes evenly, rounding up.

### Cast votes

Each faction must cast all their votes for or against the ordinance: Start with the triggering player and go clockwise.

If the ordinance gets a majority, it passes: add a check mark, move it to the board.

Otherwise, remove any neighborhood tokens and return them to the supply.
